# 01 — Integrate Ultracite Toolchain (Oxlint + Oxfmt): Replace Prettier

**What to build:** Replace the existing Prettier-only formatting pipeline with Ultracite 7.9.4 running Oxlint 1.76.0 + Oxfmt 0.61.0. The migration covers root `package.json`, .husky/lint-staged pre-commit wiring, `.vscode/settings.json` editor config, and one treewide autofix commit.

The result: Prettier is fully removed from the repo. Pre-commit runs `ultracite fix` instead. The tree has no lint violations. The editor has format-on-save wired to the Oxc extension.
