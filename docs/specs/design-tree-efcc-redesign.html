已鎖定領域規則與不變量

經 grill-with-docs 確認的跨畫面約束；實作時必須逐條滿足。

事件取消防護
任何 Active 出席存在時禁止取消聚會；全部出席先作廢（需原因）後方可取消，取消不可撤銷且需原因與審計。
部門封存防護
部門仍存在 Draft / Active 子課程時禁止封存；所有子課程須先封存。
課程封存可逆（僅 Admin）
課程封存保留全部歷史唯讀；Admin 可附審計原因恢復為 Active。
訪客出席更正
就地更新姓名/電話，寫入不可變 `GUEST_ATTENDANCE_CORRECTED` 審計事件（舊/新值、操作者、原因、時間）；時間戳與聚會綁定不變。
簽到單隱私
列印紙本電話中間四碼遮罩（`9123****`）；App 內授權領袖仍見完整號碼。
掃描器降級
相機拒絕/不支援自動內聯轉到手動 6 位聚會碼輸入（P-09），附清晰說明；手動碼在相機可用時亦常駐可達。
排程發佈 Cron
Cloudflare Scheduled Worker `*/5 * * * *` 於 `Asia/Hong_Kong` 評估 Home 內容生效/過期；過期自動回退至最新仍有效版本，否則顯示安全系統首頁。
發佈衝突（嚴格樂觀鎖）
並行編輯偵測到較新版本時必須重新載入最新版再套用；不提供強制覆寫。
Home 發佈權限
`home.publish`：Admin 依預設政策取得；Staff 需明確 capability grant。
Template B 格式
消毒後 Markdown（H2/H3、粗斜體、列表、引言、連結、外部 HTTPS 圖片 URL）；拒絕原始 HTML、script、embed。
Template A 回退
手動主打聚會無效（取消/已過期）時自動回退至全教會最早未來 Active Event。
註冊審批角色
核准即建立 Active 帳戶，預設角色為 Member；升等為個別管理能力。
會員名冊範圍
Admin/Staff 全教會 Active 帳戶；Department Manager 僅見所屬部門課程內已報名會員。
成員自取消
成員自取消報名只需確認、不需原因；管理者代取消需 Member 可見原因。
代報名錯誤
目標會員不符合條件（已在名單 / 未生效）時以彈窗明示原因，不靜默失敗。
會話過期恢復
保存消毒後完整 query（含 `?mode=&program=&task=`）；重新登入後伺服器重新授權，仍有效則還原原任務，否則安全回退 /home。
多聚會選擇返回
多個同時開放聚會選擇畫面按「返回」回掃描取景器，不中斷掃描意圖。
管理員重設密碼
本階段會員名冊唯讀；Admin 重設密碼功能延後至 #227。
狀態色階
三態徽章使用 `--success` / `--pending`(#8a5b16) / `--error` 文字+邊框+底色；狀態永不單靠顏色傳達。
順序與密度
目錄群組固定順序（會員/審批 → 課程 → 聚會/出席 → 首頁內容）；每畫面一個主 CTA、最多 5 元素群、44px 觸控目標。
