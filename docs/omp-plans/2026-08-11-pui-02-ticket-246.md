## Public seams

- `GET /api/v1/programs/catalog` — same-origin cookie-only Worker endpoint. Response `data: { catalog: ParticipantCatalogEntry[] }`; each entry `{ department: DepartmentSummary, programs: ProgramSummary[] }`. Server applies module (`program_catalog`) + discoverability policy (Listed OR scoped `program.manage`) and projects narrow rows (no check-in secrets, no capabilities). Departments with zero visible Programs are omitted.
- `web/lib/programs/program-api.ts` — `listParticipantCatalog(): Promise<{ catalog: ParticipantCatalogEntry[] }>` plus mirrored `ProgramSummary`/`DepartmentSummary`/`ParticipantCatalogEntry` browser types.
- `web/lib/programs/participant-directory.tsx` — participant landing component: search (label + clear), lifecycle filter (全部/啟用/草稿/已存檔), participation filter (全部/可報名/僅限負責人), flat rows with name/description/category/Department/lifecycle-status, and selection handoff via `buildProgramsHref({ mode: "participant", programId, hash })`.
- `web/app/programs/programs.module.css` — PUI-02 classes reuse the Official Civic Minimal tokens; 44px interactive targets; loading/empty/empty-search/error/forbidden-item panels distinct.
- Existing intent seam `programs-intent.ts` (`parseProgramsIntent`/`buildProgramsHref`) — reused unchanged; directory never invents a second URL grammar.
