## Goal

Migrate the four live Section surfaces (Events, Scanner, Care, Permissions) onto the accepted
Minimal prototype rendering (Variant A: Official Civic Minimal, accepted render at
`web/app/prototype/`), preserving current API boundaries, server-authorized navigation, the
scanner trust boundary, and truthful capability states. Where no real domain RPC exists, the
surface presents an honest building/empty state — never invented data or workflows.

## File ownership & cross-ticket markers

- Ui03 owns only the four Section routes. Shared presentation lives in a **private** Next.js
  folder `web/app/_sections/` (underscore-prefixed → not routed), so no new public route is
  created and no file owned by Ui01Shell (globals.css/middleware/auth), Ui02Profile
  (profile/shell/nav), or Ui04Settings (`web/lib/auth/`, settings UI) is touched.
- Design tokens are referenced as `var(--token, <Variant-A-fallback>)`. The global token
  names are owned by Ui01Shell and are **not yet promoted** to `web/app/globals.css`, so this
  trace uses module-scoped fallbacks equal to Variant A values and notes that
  `// TODO-ticket:193` may promote them to globals later; the `var(...)` names remain so the
  global promotion is picked up automatically when Ui01Shell merges.
- `COPY.sections.permissions` = `權限管理`. The matrix S10 header reads `權限與角色管理`, but
  the canonical zh-Hant copy source (`web/lib/copy.ts`, "Every user-facing string lives here")
  and the existing component test bind the observable heading to `COPY.sections.permissions`.
  This trace keeps `COPY.sections.permissions` so the acceptance gate stays green and copy
  stays centralized. (Deviations from the matrix's illustrative English-suffixed prototype
  strings are intentional: prototype headings like `聚會管理 (Events)` carry an English helper
  annotation that is not production copy and would break the exact-match heading assertion.)
