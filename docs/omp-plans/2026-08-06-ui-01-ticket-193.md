## Scope decision: middleware

`web/next.config.ts` is a static export (`output: "export"`, ADR-0017). Next.js middleware edge runtime does **not** run under static export, and authorization is already enforced server-side by the Cloudflare Worker's role checks on the auth endpoints (not by Next middleware). **No `middleware.ts` is added** — adding one would either be dead code or risk changing auth behavior. This is recorded as a deliberate non-change.
