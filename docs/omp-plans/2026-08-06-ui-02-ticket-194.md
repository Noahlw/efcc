# UI-02 Ticket #194 — Authenticated Shell, Profile & QR Identity (Acceptance Trace)

**Owner:** Ui02Profile (worktree `ui-02-194`, branch `ui-02-194`)
**Date:** 2026-08-06
**Design authority:** `web/app/prototype/` (Variant A accepted render), `DESIGN.md`, `.impeccable/design.json`, `docs/specs/079-minimal-product-redesign-contract.md` (matrix rows S5, S11–S15).
**Parallel agents:** Ui01Shell (globals.css, tokens, middleware, public/auth routes), Ui03Sections (events/scanner/care/permissions pages), Ui04Settings (account-settings). No shared-file edits: Ui01Shell owns `globals.css`/`middleware.ts`; this ticket edits only `web/app/profile/`, `web/lib/` shell components, `web/lib/copy.ts`, `web/lib/sections.ts`, and its own test file.

## Scope

- Migrate the authenticated shell (header, nav), Profile surface, QR identity presentation, and account-facing loading / session-expiry / forbidden / empty / network-error / retry states onto the accepted Minimal prototype.
- NO new account capabilities. Preserve bootstrap data, server-authorized Section visibility, immutable `User_ID`, and QR identity exactly.

## Ownership & coordination contract

- Shell chrome layout comes from Ui01Shell's `.shell` / `.shell-content` globals: `.shell { height:100dvh; display:flex; flex-direction:column; overflow:hidden }`, `.shell-content { flex:1; min-height:0; overflow-y:auto; padding-bottom:calc(60px + safe-area) }` (padding-bottom cleared at ≥800px). Ui02Profile adds the `ShellHeader` (SealSlot + full title + 登出) as a `flex-shrink:0` sibling and keeps `NavBar` (nav-phone / nav-desktop / nav-item) class-based so Ui01Shell's global styling applies.
- Tokens referenced from `.impeccable/design.json` (`--surface`, `--surface-raised`, `--ink`, `--ink-muted`, `--line`, `--line-strong`, `--accent`, `--accent-deep`, `--focus`), always with a literal fallback (`var(--token, fallback)`) so the module renders correctly before and after Ui01Shell's token merge.
- `GuardedSection` forbidden presentation restyled per S13 (coordinated with Ui03Sections; behavior unchanged, their absent-section test asserts only `COPY.error.forbidden` text + heading absence).
