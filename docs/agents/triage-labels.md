# Triage labels

Use these exact names for the five canonical triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | A maintainer must assess the incoming issue. |
| Needs information | needs-info | Work is waiting for information from the reporter. |
| Ready for agent | ready-for-agent | The issue is sufficiently specified for agent work. |
| Ready for human | ready-for-human | The issue needs human implementation or judgment. |
| Won't fix | wontfix | The issue will not be actioned. |

ready-for-agent describes issue readiness; it does not authorize scope changes, merge, deployment, or release.
